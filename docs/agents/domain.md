# Domain docs

## Layout and reading rules

Single-context: root `CONTEXT.md` and `docs/adr/`.

Before exploring, read `CONTEXT.md` and ADRs relevant to the work.
If absent, proceed silently. Domain-modeling creates these documents
when terms or decisions are settled.

## Vocabulary

Use terms defined in `CONTEXT.md`.
If a needed concept is missing, reconsider the term or flag the gap
for domain-modeling.

## Decisions

Explicitly flag proposals that conflict with an existing ADR,
including the reason for reconsidering that decision.
